# Mi Negocio - Kivy

App de gestión básica para un negocio.

## Incluye
- Resumen de ventas, gastos, saldo y clientes
- Registro de ventas
- Registro de gastos
- Registro de clientes
- Base de datos SQLite local

## Ejecutar en Windows
```cmd
python -m pip install -r requirements.txt
python main.py
```

## APK
El proyecto incluye `buildozer.spec` para preparar la compilación Android con Buildozer.
